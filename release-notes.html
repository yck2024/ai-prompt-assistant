Release notes

What's changed in AI Prompt Assistant, newest first.

Unreleased Coming in the next version

These changes aren't in the Chrome Web Store version yet. Until the next version, the store has version 3.2.2.

Fixed: ChatGPT works again when you're signed in

  • Typing // on ChatGPT opens the prompt menu again when you're signed in. ChatGPT changed its message box, so the menu stopped appearing for signed-in users.
  • Picking a prompt with Enter now inserts it, instead of sending a message that says “//…”.

Fixed: new addresses

  • Works on the new addresses some chat tools moved to: duck.ai (DuckDuckGo AI Chat), copilot.com (Microsoft Copilot) and notebook.google.com (NotebookLM).

New: add your own sites

  • A new Your Sites section in settings lets you use your prompts on any other chat site. Type a domain such as perplexity.ai (it covers www.perplexity.ai too) or paste a full URL from the address bar, then click Add Site.
  • Chrome asks you to allow access to that one site. The extension gets no access to other sites until you add them.
  • Reload tabs already open on the site before you type // there.
  • Removing a site stops the extension running there and gives back its access.
  • Some sites use message boxes the extension can't type into. See the setup guide.

3.2.2 Current Chrome Web Store version

  • Works on ChatGPT, Claude, Google Gemini, Google AI Studio, DuckDuckGo AI Chat, Microsoft Copilot (including Microsoft 365), Glean and NotebookLM.
  • Known issue: on ChatGPT, // doesn't open the menu while you're signed in. Fixed in the next version (see above).

AI Prompt Assistant is a Chrome extension: type // in an AI chat to drop in your saved prompts.
